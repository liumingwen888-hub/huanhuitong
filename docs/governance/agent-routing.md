# 代理路由

状态：APPROVED。交付状态：READY。

默认由主 Codex 完成工作，不使用子代理。

## 可用角色

- architect：只读评审跨领域边界、依赖方向、运行拓扑或资金流；不修改文件。
- researcher：只读查询官方资料；适用于 Telegram、链、供应商、法规与平台政策，不将研究自动变成产品决定。
- reviewer：只读检查规格、文档、代码和验证证据的一致性。
- security-reviewer：只读检查身份、凭证、密钥、账本、权限、回调、恢复与审计边界。
- implementer：只在已批准书面计划和明确文件分配下开发，不自行扩展范围。

## 使用门槛

只有用户明确允许，或已批准计划明确要求，并且子任务相互独立、不修改同一文件、不依赖未完成共享状态时，才允许派发。所有结果都必须由主 Codex在当前工作区重新读取、运行检查并核验；子代理的“完成”声明不是证据。

资金、安全、身份和权限设计即使经过专家代理评审，最终决定仍必须进入对应权威文档并经过用户审查。
