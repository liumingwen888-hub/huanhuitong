# 备份与恢复

需求状态：APPROVED；RPO/RTO DRAFT。交付状态：DESIGNING。

PostgreSQL 业务与账本、配置版本、审计和必要外部关联数据进入加密备份。密钥材料使用独立密钥管理与恢复程序，不以数据库备份明文承载。备份需要自动校验、访问隔离、异地副本、保留策略和不可篡改证据。

## 恢复流程

1. 声明事故并暂停新资金订单和外部副作用。
2. 选择经校验恢复点，在隔离环境恢复。
3. 验证 schema、总账平衡、余额投影、订单、Outbox/Inbox、任务租约和审计连续性。
4. 对账恢复点后的链上交易、广播、供应商订单和资金余额。
5. 将未知动作保持 UNKNOWN，主动查询，不重放外部付款。
6. 经 Maker-Checker 批准后分阶段恢复只读、入站、内部资金和外部出站。
7. 记录数据缺口、补偿分录、验证证据和事故复盘。

恢复演练必须包含备份损坏、时间点恢复、任务重复、Outbox 重放、广播结果未知和供应商在途。只有演练证明不会重复资金动作，才能通过发布门禁。
