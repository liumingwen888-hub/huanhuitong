# 发布门禁

需求状态：APPROVED。交付状态：DESIGNING。

当前没有发布授权或发布候选。

未来每次发布必须满足：

- 需求、设计、威胁模型和计划已批准，差异与计划一致。
- 格式、静态分析、类型、单元、属性、数据库集成、契约和端到端检查通过。
- 资金、身份、权限、回调、重放、并发、UNKNOWN 和恢复路径通过安全审查。
- 迁移可验证、可回滚或有前向修复策略，且不破坏账本历史。
- 指标、告警、运行手册、对账、备份恢复和容量证据齐备。
- 合规、供应商、链和密钥门禁满足目标环境。
- 发布采用渐进策略，明确停止条件、回滚负责人和回滚后对账。
- 文档、索引、current、next、verification 和 progress-log 已同步。
- 用户明确授予生产部署权限，授权值大于 0。

失败命令、未执行检查或未解决高风险不得被“已知问题”标签绕过。
