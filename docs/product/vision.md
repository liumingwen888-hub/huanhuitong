# 产品愿景

需求状态：APPROVED。交付状态：DESIGNING。

换汇通是一个托管账户与资金服务平台。第一阶段以 Telegram Bot 为用户入口，提供自动注册、资产余额、充值、提现、内部转账、领取、红包、数字资产换汇、法币代付、账单、安全和客服能力；管理侧提供风控、费用、审批、审计、对账、监控与恢复能力。

Telegram Bot 不是账户本身。平台内部 UID 是身份与资产主体，Bot 和未来 Android、iOS 原生 App 都只是适配渠道，必须访问同一 UID、资产账户、权威余额、复式账本和风控策略。

## 产品原则

- 资金安全与可证明正确性优先于流程便利。
- 每次资金变化经复式账本，业务订单与账本可双向追踪。
- 外部响应 UNKNOWN 时保持不确定，不通过猜测重付。
- 首次 /start 自动、幂等创建或进入 UID，不设置“注册/登录”双入口。
- 未启动 Bot 的收款人通过一次性领取深链进入，不假设 Bot 能主动联系。
- 重要身份变更、账号恢复、支付密码重置和 UID 冲突彼此独立。
- 供应商、链、资产、国家和合规条件未确认时保持 DRAFT，不虚构契约。

成功标准是：用户在任何已支持渠道看到一致资金事实；重复、并发、重试和恢复不会造成重复入账、重复付款或负余额；运营人员无法绕过身份、账本和审批底线。
