# 决策：产品基线

日期：2026-07-20。需求状态：APPROVED。

## 决定

换汇通第一阶段以 Telegram Bot 为入口，提供托管账户、内部资金流、红包、换汇、提现和法币代付；未来原生 App 只是新增渠道。所有渠道共享内部 UID、资产账户、权威余额、复式账本和风控。当前不采用 Telegram Mini App。

## 理由

把渠道与账户主体分离可避免 Telegram 身份变化污染资金主键，也允许未来 App 复用同一事实源。阶段 0 先建立产品与架构基线，防止资金能力在缺少链、供应商、合规和安全决定时过早实现。

## 影响

Telegram、App 和后台均为适配层；领域规则与资金写入留在平台核心。当前业务代码开发授权保持 0，详细范围见 [scope.md](../product/scope.md)。
