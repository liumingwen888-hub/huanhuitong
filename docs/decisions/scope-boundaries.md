# 决策：范围边界

日期：2026-07-20。需求状态：APPROVED。

## 决定

第一阶段规划覆盖资金平台的用户、资金、管理、安全和运维闭环；Android、iOS、手机充值、商户能力和理财为 LATER。未来能力当前只描述业务边界，不创建菜单、API、表、依赖或空实现。理财在收益、赎回、风险承担与法律边界确认前不得推进。

## 理由

资金产品的最小完整范围必须包含对账、审计、监控和恢复，而不仅是前台流程；同时不能用占位实现掩盖尚未决定的供应商与法律责任。

## 影响

路线图按阶段 0 至 11 推进，每阶段经过需求、设计、威胁模型、计划、TDD、审查、验证、文档和验收。当前只交付阶段 0 文档，详见 [roadmap.md](../plans/roadmap.md)。
