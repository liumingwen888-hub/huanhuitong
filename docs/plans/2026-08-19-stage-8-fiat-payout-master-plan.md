# 阶段 8 法币代付供应商接入 总体规划

计划版本：`v0.1（需求确认中）`。计划状态：`DRAFT`。

基线：阶段 1–7 VERIFIED（阶段 7 于 2026-08-19 用户验收通过）。

## 目标

在已验证的资金管线之上建立**法币代付能力**：路线能力、代付报价、收款人引用、资金冻结、供应商提交（端口隔离）、回调验真接收、UNKNOWN 查询优先、结算/释放/冲正与对账。真实供应商合同/凭证属生产阶段独立授权——合成期推进至 FakeProvider 边界（与充值/提现/换汇同模式）。

## 边界事实（P0-5）

- 供应商合同、国家清单、真实费率/限额、SLA、回调格式：**不虚构**（领域红线）——合成期用单一合成路线（USD-FIAT）+ 配置驱动参数。
- 真实连接授权为 0；上线前需真实合同映射与数据驻留评审。

## 核心设计决策（需确认）

1. **支付密码门**：法币代付 = 资金出平台，建议**设**（复用 S6-2 七维绑定合同，operationType 扩展 'fiat-payout'）？
2. **收款人信息**：合成期仅存 **token 引用 + 摘要哈希**（零明文银行细节），真实加密与字段权限生产阶段？
3. **供应商映射**：provider_configs 版本化只增不改（market_configs 同型），FakeProvider 经注入消费？
4. **回调验真**：HMAC 签名验证端口（接口 + Fake），验真失败按永久错误拒绝（不进入任何状态迁移）？
5. **UNKNOWN 处理**：查询优先原则——任何回调缺失/超时/不确定结果必须先 QueryPayout，绝不推断失败、绝不自动重付？
