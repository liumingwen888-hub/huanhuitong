# 阶段 3 最小横切资金合同、复式账本、余额和账单 总体规划

计划版本：`v0.1（需求确认中）`。计划状态：`DRAFT`。交付状态：`DESIGNING`。

基线：阶段 1、2 VERIFIED（2026-08-17 用户验收通过）。本文是阶段 3 需求确认与任务分解草案；进入设计/实施前须完成 ledger-model/fees-risk/admin-audit/bills 领域细节确认与独立书面计划复审。

## 目标

在已验证的身份与安全底座上建立**资金事实核心**：复式账本作为一切资金变化的唯一写入入口、余额投影、横切最小合同（费用/风险/限额/审计/配置版本/订单-账本关联/对账接口）。完成后具备承接阶段 4–8（充值/转账/红包/提现/换汇/代付）的完整资金地基。

## 红线（引用 [AGENTS.md](../../AGENTS.md) 与 [ledger-model](../architecture/ledger-model.md)）

- PostgreSQL 业务与资金事实源；复式账本唯一资金写入口；业务模块不得改余额/账本表。
- 命令原子、借贷平衡、幂等、可审计、防并发负余额；历史分录不可变，纠错冲正。
- 金额整数最小单位 + 十进制字符串跨界；禁 JS number。
- UNKNOWN 不推断；释放/重试先查权威状态。
