## 目标

在已验证的资金管线之上建立**运营平面**：独立管理员认证（MFA）、RBAC 与数据范围、审批工作台（统一提现/代付审批）、对账与运营视图、追加式审计查询、版本化配置发布——领域红线：不直接改余额或账本表、不访问私钥、发起人不审批自己。

## 现状盘点

- 已有：admin_principals/admin_role_grants（V5 五角色）、AdminAuthorizer、Maker-Checker 双审（S6-3/S8）、全部审批/对账服务、版本化配置表（markets/providers/policies + ConfigStore）。
- 缺失：管理员登录凭据与会话、HTTP API 层与 RBAC 中间件、统一审批请求实体、审计查询接口、配置发布流、admin-web 前端。

## 已裁决的设计决策（2026-08-19 用户通过）

1. **前端技术**：React 18 + Vite + TypeScript（workspace 内新 app admin-web）。
2. **管理员认证**：argon2 密码 + TOTP 强制 + 30 分钟短会话 + 高风险重认证。
3. **首批页面**：审批/对账/审计/配置四页；Break-Glass 延后阶段 10。
4. **API 形态**：platform 内 HTTP 模块（REST/JSON + Bearer 会话）。
5. **审批统一实体**：approval_requests 编排层，不动已验证双审服务。
